# Numerical Model for TCSPC Raman LiDAR Gas Detection
This Google Colaboratory notebook implements a numerical model for Time-Correlated Single-Photon Counting (TCSPC) signal processing, specifically applied to Raman LiDAR for the stand-off detection of hydrogen and nitrogen (H2 and N2). Developed by Jiaying Wang, Andrew Lockwood, and Charles N. Ironside (Curtin University), the code supports experimental data analysis and was developed for the paper "Time-correlated single-photon counting (TCSPC) Raman LiDAR for stand-off detection of hydrogen".

**LiDAR Equation Update:** The spatial sample distance $\Delta z$ in the LiDAR equation has been corrected to use the TCSPC range-bin length, $\delta z = c\delta t/2$, where $\delta t$ is the TCSPC time-bin width and $c$ is the speed of light.
We now use $\Delta z$ to designate range uncertainty. The range uncertainty is associated with the laser pulse width, $P_w$, which contributes to the spatial resolution, with a range resolution of $\Delta z = cP_w$.  If $P_w>\delta z$, then the laser pulse width dominates the range uncertainty. In summary, there are two contributions to the spatial resolution: the sample region length, $\delta z = c\delta t/2$, and the range uncertainty $\Delta z = cP_w$. For the case discussed in the publication (see below) $\delta t=50 ps$ and $P_w= 1.1 ns$, and so the spatial resolution is dominated by the pulse width.
